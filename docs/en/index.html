Connected devices

Luna on your computer and phone on the same Wi-Fi connect directly – no Luna servers, no accounts. Pair them with a QR code, then send a page to the other screen, move photos without losing quality (like LocalSend), keep the same bookmarks and tabs, share one clipboard, and use your phone as a remote for videos on the computer. Every feature can be switched off on its own, and the whole connection is off by default.

Computer: Settings → Connected devices. Phone: Menu → Devices. The connection is encrypted (TLS with pinned certificates), and files arrive byte for byte in Downloads/Luna. The app's interface is in Polish.

Download and install

Ready-made builds for Windows, Linux, macOS and Android – no Python needed. You'll find them all on the latest release page.

Windows 10 / 11

Download Luna-Windows-Setup.exe and run it – no administrator rights needed. Once installed, Luna updates itself, so you only download it once. There's also a portable version to unzip: Luna-Windows.zip.

Linux

Download Luna-Linux-x86_64.AppImage, make it executable (chmod +x) and double-click to run.

macOS

Apple M1 and newer. Easiest with one command in Terminal – Luna lands in Applications and opens without a warning:

curl -fsSL https://raw.githubusercontent.com/z4k0lzakol/Luna/main/packaging/install-mac.sh | bash

Or download Luna-macOS-arm64.dmg and drag Luna into Applications – the first time macOS will block it; then go to System Settings → Privacy & Security → Open Anyway.

Android (preview)

On your phone, download Luna-Android.apk and open it – Android will ask you to allow installing from outside the Play Store. An iPhone version will follow (it requires an Apple signature).

Smart App Control (Windows 11): if you have it turned on, Windows will block the released Luna for now – it doesn't allow new programs without a digital signature to run, and Luna's signature is still in the works. Until then, run Luna from source (see below). Without a signature, Windows may show “Windows protected your PC” on first launch (click More info → Run anyway), and macOS may say “Luna” Not Opened (the workaround is in the macOS card above). The first launch opens a tour that shows you where everything is and brings over your bookmarks, history and passwords. Luna downloads and installs new versions by itself (on Windows, macOS and Linux – after verifying the checksum, when you close it; you can turn this off in Settings → Updates).

Running from source (for developers)

With Python 3.12 or newer:

git clone https://github.com/z4k0lzakol/Luna.git cd Luna python -m pip install -r requirements.txt python luna.py

A Luna cloned with git updates in one click (Settings → Updates).

FAQ

Is Luna available in English?

The browser's interface is in Polish. Web pages themselves work in any language, and Luna can translate pages from any language in one click.

Is Luna just Chrome?

Luna renders pages with the Chromium engine (via Qt WebEngine), so websites work just like in Chrome. But there are no Google services or accounts inside – the interface, ad blocking, passwords and every feature are Luna's own.

Who makes Luna?

A single maintainer – z4k0lzakol, who is responsible for the code, reviews and releases. Quality is guarded by automated tests that run a real Luna, and by launch and install tests of every release on GitHub. The software is provided without warranty, so keep a backup of anything important. Report bugs on GitHub.

Is Luna free?

Yes. Luna is free software under the GNU GPL v3: no fees, no ads, no data collection. You can also modify and share it under the terms of the license. Details in the terms of use (in Polish).

Do I need to create an account?

No. Luna has no accounts and no servers. You only sign in to the websites you use – just like in any browser.

Does signing in to Google (Gmail, YouTube) work?

Yes. Google blocks browsers it considers “embedded in another app”, so on Google's sign-in page alone Luna presents itself as Firefox – once you're signed in, everything works normally and your session is remembered.

Do Chrome extensions work?

No, but the most popular ones are built in: ad blocking, a password manager, a translator, dark mode, SponsorBlock and screenshots.

How do I update Luna?

You don't have to. The installed Luna (Windows, macOS and Linux) checks for new releases on its own, downloads them in the background, verifies the checksum (and on Windows the signature), and installs it when you close the browser – or right away if you click “Restart and update”. Your tabs, passwords and settings stay. On Android, Luna downloads the new version and opens the system install prompt. On a Mac this means you get past Apple's warning only once, on first install.

How do I move my data from another browser?

The first-launch tour imports bookmarks, history and passwords from Chrome, Edge, Brave, Opera and Vivaldi. Bookmarks from Firefox or Safari can be loaded from an HTML file (Bookmarks → Import file).

Where is my data stored?

Only on your computer – in your user folder, in files whose names start with .luna. Passwords are encrypted by the system (Windows DPAPI; on Linux and macOS, the system keyring). Details in the privacy policy (in Polish).

Does Luna work on a Mac or Linux?

Yes – there are ready-made builds: an AppImage for Linux and a .dmg for macOS (Apple M1 and newer). These are the first releases for those systems; some features were designed with Windows in mind (e.g. controlling media players through the system), so they may behave differently.

What about phones?

Yes, on Android – as a preview: download Luna-Android.apk on your phone. The same look, tabs and spaces, menu, AI assistant, messengers, widgets and ad blocking. The iPhone version is ready in the code and will follow once it has an Apple signature.

Code signing policy

The code signing policy for Luna's Windows releases.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation is in preparation – current releases are not signed yet.

  • What gets signed: only files built automatically by GitHub Actions from the source code of the Luna repository – Luna.exe and the Luna-Windows-Setup.exe installer. Libraries from other projects (Qt, PyQt6, Python) are included unmodified.
  • Committers and reviewers: z4k0lzakol – Luna is a one-person project; contributions from others are reviewed before being merged.
  • Approvers: z4k0lzakol – every release is manually approved for signing.
  • Privacy: Luna does not transfer data to other systems, except for the services needed by the features you use – details and how to turn them off are in the privacy policy (in Polish).
  • Uninstalling: in Windows Settings (Apps → Luna → Uninstall); user data is kept.
